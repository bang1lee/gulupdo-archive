How it works

1. 질문 입력 → /api/lab-stream이 프롬프트를 합성
2. 클라이언트가 WebSocket 연결, 프레임 수신
3. 캔버스에 hit-zone 좌표 등록 → 클릭 시 부모 프롬프트 + 영역 라벨로 재요청
4. 경로(/SoC/GPU…)는 컨텍스트로 누적
